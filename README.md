NEXIS ERP + E-COMMERCE
Enterprise Resource Planning Platform for Modern Businesses
1. Overview

Nexis ERP is a scalable enterprise platform that integrates ERP and E-commerce into one cohesive system.
It was designed for companies that require modular management, real-time data flow, and secure multi-company operations.

The architecture focuses on performance, maintainability, and clean separation of responsibilities, combining business logic and technology under a unified ecosystem.

2. Core Capabilities

Multi-company architecture with isolated MongoDB collections

Complete inventory, product, and order management

Role-based authentication and authorization (JWT)

Real-time synchronization using Server-Sent Events (SSE)

Modular API structure compatible with REST clients

Reporting, metrics, and analytics modules

Cross-platform support: React Web + Kotlin Android

3. Technology Stack
Layer	Technologies
Backend	Node.js, Express, MongoDB, Mongoose, FastAPI
Frontend	React.js (Web), Kotlin (Android)
Security & Auth	JWT, bcrypt, role-based access control
Communication	RESTful APIs, Server-Sent Events (SSE)
Infrastructure & Tools	Docker, PM2, Git, Vercel, Postman
